## Control Signal

| Signal | Meaning |
|---|---|
| **Approval Freshness** | Prior approval is checked against current operating conditions. |
| **Change Detection** | Material changes are surfaced before continued use. |
| **Trigger Classification** | Model, prompt, data, source, tool, access, policy, environment, and business-use changes are categorized. |
| **Boundary Impact** | Critical control changes force stop or renewed review. |
| **Evidence Preservation** | Owners, records, change summary, and outcome are reconstructable. |
| **Lifecycle Governance** | AI review continues after launch. |
