# Contributing

## Public-Safe Contributions Only

Contributions should strengthen the public-safe enterprise AI revalidation model.

Accepted contribution types:

- documentation improvements
- public-safe revalidation scenarios
- clearer decision logic explanations
- sandbox usability improvements
- revalidation trigger improvements
- approval freshness checklist improvements
- public-safe expected outcomes
- buyer or pilot-readiness templates

Do not contribute:

- credentials
- customer data
- private client artifacts
- protected Elyria Systems runtime machinery
- confidential diagrams
- proprietary implementation internals
- production logs
- regulated data

## Review Standard

A contribution should preserve the repository purpose:

```text
Detect when prior AI approval becomes stale before changed systems continue producing enterprise consequence.
```

## Decision Language

Use the repository decision model consistently:

```text
ADMIT / HOLD / REFUSE / REVALIDATE
```
